# File-level licensing

This repository uses two licences because formal code and scholarly text have different reuse patterns.

## MIT

The following are licensed under the MIT License in `LICENSE`:

- `coq/`
- `scripts/`
- `.github/`
- `Makefile`
- `Dockerfile`
- `.dockerignore`
- machine-oriented metadata and build configuration

## CC BY 4.0

The following are licensed under Creative Commons Attribution 4.0 International as described in `LICENSE-TEXT.md`:

- `paper/`
- `docs/`
- `README.md`
- `REPRODUCE.md`
- `CONTRIBUTING.md`
- `SUPPORT.md`
- `CODE_OF_CONDUCT.md`

When a file contains an explicit SPDX identifier, that identifier controls. Otherwise this directory-level policy applies.
