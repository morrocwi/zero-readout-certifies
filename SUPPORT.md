# Support

Use GitHub issues for reproducibility failures, mathematical counterexamples, prose-to-formalization mismatches, prior-art corrections, and documentation problems.

Before opening an issue, include:

- prover and version;
- operating system or container image;
- the exact command run;
- complete error output;
- the commit SHA tested.

For general questions, open a discussion-style issue rather than contacting maintainers privately. Security-sensitive supply-chain reports belong under `SECURITY.md`.
