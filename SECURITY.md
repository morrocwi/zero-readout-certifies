# Security policy

This repository contains formal proofs and document build tooling; it does not provide a network service. The relevant security risks are therefore supply-chain and artifact-integrity failures.

Report privately when a problem could cause users to execute untrusted code, consume a substituted release artifact, or accept a false verification result. Use GitHub's private vulnerability reporting feature when available. Do not include secrets or personal data in a public issue.

Mathematical errors, incorrect claims, and ordinary reproducibility failures should be reported publicly through the issue templates so they can be discussed and corrected transparently.

Supported version: the latest tagged release and the current `main` branch.
